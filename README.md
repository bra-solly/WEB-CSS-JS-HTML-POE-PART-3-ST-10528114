Project Overview
Thunder Brothers Car Wash is a fictional car wash business based in Rondebosch, Cape Town. The website allows customers to:

View wash packages and pricing (Basic R120, Standard R200, Premium R450)
Learn about the company and team
Send a contact message via a validated form
Book a wash with a date, time, and service selection
See an estimated price calculation in real time
Features
Responsive layout (desktop, tablet, mobile)
Sticky navigation bar with smooth scrolling
Hero section with call-to-action
Three wash package cards with images
Search/filter functionality for services
Lightbox image modal (click to zoom)
Contact form with email and phone validation (SA format)
Booking form with date validation (no past dates)
Live price calculator on the booking form
Custom confirmation modals (no browser alerts)
Mobile hamburger menu toggle
Scroll-reveal animations using Intersection Observer
Active navigation highlighting on scroll
Floating "Book Now" button on mobile
